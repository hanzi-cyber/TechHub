# TechHub 接口文档

## 基础信息

- **Base URL**:`http://localhost:8080`(前端走 vite 代理,请求路径带 `/api` 前缀)
- **统一返回格式**:

```json
{
  "code": 200,
  "message": "成功",
  "data": {}
}
```

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录/token 失效 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 系统内部错误 |
| 1001~4002 | 业务错误(用户名已存在、重复点赞等) |

- **认证方式**:登录后返回 `token`,后续请求在请求头加 `Authorization: Bearer <token>`
- **分页返回格式**:`data` 为 `{ "records": [], "total": 0, "pageNum": 1, "pageSize": 10 }`

## 一、认证模块

### 1. 注册
`POST /api/auth/register`

请求体:
```json
{ "username": "zhangsan", "password": "123456", "email": "a@b.com" }
```
返回:`{ "code": 200, "message": "成功", "data": null }`

### 2. 登录
`POST /api/auth/login`

请求体:
```json
{ "username": "zhangsan", "password": "123456" }
```
返回:
```json
{
  "code": 200,
  "message": "成功",
  "data": { "token": "xxx", "user": { "id": 1, "username": "zhangsan" } }
}
```

### 3. 退出登录
`POST /api/auth/logout`(需登录)

## 二、用户模块

| 方法 | 路径 | 说明 | 参数 |
|---|---|---|---|
| GET | `/api/user/me` | 当前用户信息 | 无 |
| GET | `/api/user/{id}` | 用户主页信息 | 路径 id |
| PUT | `/api/user/me` | 更新资料 | body: `{ "bio": "...", "avatarUrl": "..." }` |
| GET | `/api/user/{id}/posts` | 用户的帖子 | query: pageNum, pageSize |
| GET | `/api/user/{id}/followers` | 粉丝列表 | query: pageNum, pageSize |
| GET | `/api/user/{id}/following` | 关注列表 | query: pageNum, pageSize |

---

## 三、帖子模块

| 方法 | 路径 | 说明 | 参数 |
|---|---|---|---|
| GET | `/api/posts` | 帖子分页列表 | query: pageNum, pageSize, sort(latest/hot), keyword, tagId |
| GET | `/api/posts/{id}` | 帖子详情 | 路径 id |
| POST | `/api/posts` | 发布帖子 | body: `{ "title", "content", "summary", "tagIds" }` |
| PUT | `/api/posts/{id}` | 编辑帖子 | 路径 id + 同上 body |
| DELETE | `/api/posts/{id}` | 删除帖子 | 路径 id |

## 调试提示

1. 把 `api-doc/openapi.json` 导入 Apifox(导入 → OpenAPI/Swagger),会自动生成全部接口
2. 在 Apifox 里配置环境变量 `baseUrl = http://localhost:8080`
3. 登录后把返回的 `token` 填到「全局请求头」的 `Authorization: Bearer <token>`,后续接口自动带上
